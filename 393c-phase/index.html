Dense graph limits · Microcanonical constraints · Entropy maximization

A graphon

A symmetric function \(g\colon[0,1]^2\to[0,1]\). In a block model, side lengths give vertex-class proportions, block areas give pair proportions, and colors represent edge probabilities. Diagrams use graphon coordinates: origin at the bottom left, with \(y\) increasing upward.

\[e(g)=\iint g(x,y)\,dx\,dy\]
\[\begin{aligned}t(g)&=\iiint g(x,y)g(y,z)\\&\qquad\cdot g(z,x)\,dx\,dy\,dz\end{aligned}\]

A variational problem

\[S(g)=\iint h(g(x,y))\,dx\,dy\]
\[\begin{aligned}h(p)=-\tfrac12\bigl[&p\log p\\&+(1-p)\log(1-p)\bigr]\end{aligned}\]

Maximize over all graphons satisfying \(e(g)=e\) and \(t(g)=t\). This entire page uses the course’s half-Shannon entropy \(h\). Papers using \(H=2h\) report twice these entropy values, with the same optimizers. Uniqueness is always up to graphon equivalence.

Three levels of evidence

Feasible construction: the model has the required densities.

Numerical winner: it beats the candidates tested.

Global optimum: it attains the maximum over all allowed graphons; uniqueness is a separate claim.

This is the (e,t) constraint plane, not the Lagrange-multiplier plane of a canonical ERGM.
