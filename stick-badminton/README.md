# 火柴人羽毛球 · 双人对决

原创的浏览器街机小游戏，灵感来自经典双人火柴人羽毛球。两个人在同一台电脑上共用键盘，不需要账号或下载插件。美术、动作、音效均由代码绘制或合成，不包含原版游戏素材。

## 怎么玩

| 操作 | 蓝方 P1 | 红方 P2 |
| --- | --- | --- |
| 左右移动 | A / D | ← / → |
| 跳跃 | W | ↑ |
| 挥拍 / 发球 | S（或 F） | ↓（或 K） |
| 扣杀 | G | L |

空格开始或继续，P / Esc 暂停，M 切换音效，R 返回开局画面。触屏设备提供双人按钮，推荐横屏或电脑键盘。

**蓄力发球：**轮到自己发球时，按住 S（蓝方）或 ↓（红方），观察球场上方的力量条，松开按键发球。短按发近球，长按发远球，约 1.2 秒蓄满；蓄满后不会自动发出。F / K 和触屏「挥」按钮也支持同样操作。暂停、切换窗口或触控中断会取消蓄力，回来后重新按住即可。回合中的挥拍和扣杀仍按原来的方式操作。

11 分制，需净胜 2 分，15 分封顶；每球得分，得分方发下一球。球落在自己半场时对方得分。两侧后墙可以反弹救球，碰墙后原击球者也能在自己半场再次救球（街机规则）。

每次出球根据球与人的相对位置、击球高度、移动速度和来球速度计算，不使用统一的固定落点。身前击球偏向平快进攻，身后击球偏向高弧线救球，低点击球向上挑，跳起后高点击球可以下压扣杀。靠近球挥拍，可以按住连续挥拍，看准时机更稳。部分键盘有多键冲突，可换用 F / K 挥拍或触屏按钮。

## 本地运行

本项目无依赖，无需安装包或构建。由于使用 JavaScript 模块，请通过 HTTP 打开，不能直接双击 index.html。

```sh
python3 -m http.server 8765
```

在本目录运行后打开 http://localhost:8765 。也可以把整个文件夹放在 GitHub Pages 等静态网站目录中。

## 验证

```sh
node --test engine.test.mjs
```

`engine.mjs` 负责固定小步长物理、计分和比赛状态；`game.mjs` 负责绘制、双人输入、音效、暂停和界面。浏览器失焦会自动暂停；音效设置仅保存在本机。
