Browser port dated 2026-10-29:
- Builds the original C++ search and full NNUE runtime using official Emscripten
  3.1.74, WASM SIMD and pthreads. The network is not reduced or quantized again.
- source.patch exposes UCI initialization and single-command execution so a
  Web Worker can receive commands without blocking on stdin. Native loop
  handling remains available. No search, scoring or NNUE logic was changed.
- worker.js adds bounded browser settings, chunk caching, byte counts and
  SHA-256 verification, and preserves raw UCI lines including mate values.
- The network is split only for hosting. The worker verifies all three chunks
  and the joined original file before exposing it to the engine.
- Defaults: 2 search threads, 128 MiB hash. Browser wrapper limits: 4 search
  threads, 256 MiB hash. WASM initial memory 512 MiB, maximum 2 GiB.

Complete corresponding engine source is included as
AB-JChess-v0.2d-source.tar.gz, together with source.patch and build.sh.
