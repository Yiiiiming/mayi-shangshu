# 观棋 · 揭棋

默认与 AI 对弈，执红。[实战录入](https://yiiiiming.github.io/mayi-shangshu/jieqi/?mode=record)从初始局面输入双方走法；暗子移动填揭子，自己暗吃填身份，对方暗吃保持未知。

- 四级 AI 对应每步 10、30、60、120 秒，实战分析使用相同预算。
- 最多五种不同走法，显示引擎胜率、和率和杀棋提示。
- 点击一条候选显示该路线；支持新局、悔棋、翻转。
- 桌面按视窗高度缩放完整棋盘；手机全宽棋盘，下方显示候选。

## 运行

发布目录：`jieqi/`。网页：[观棋揭棋](https://yiiiiming.github.io/mayi-shangshu/jieqi/)。本地使用静态 HTTP 服务，不能直接用 `file://` 打开。

完整 AB-JChess v0.2d + 143,667,546 字节 NNUE，浏览器本地计算。网络分三片校验并缓存。默认 2 线程、128 MB 搜索缓存，最多 4 线程、256 MB。多线程需要支持隔离环境的现代浏览器。

## 边界与来源

胜和负是估计，未独立校准。杀棋基于已知信息，揭子后可能变化。尚未实现长将、长捉的完整赛事裁判。刷新会重新开始。

引擎源码、补丁、构建脚本和 GPL 许可证位于 `engine/`。网络原始发布包没有独立网络许可文本，见 `engine/NNUE-NOTICE.txt`。界面参考 [Canva 设计](https://canva.link/w4cnnnxmp58u87u)。
