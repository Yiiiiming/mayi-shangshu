# Everything 100

Public community ratings from 0 to 100.

Website: https://yiiiiming.github.io/xxx/everything-100/

This folder contains the public GitHub Pages frontend. Items and community
scores are stored in the shared cloud database, so every visitor sees the
same collection. The API host is configured in src/app.js.

Each browser keeps an anonymous credential to edit its own scores. Clearing
browser storage starts a new identity; existing public scores remain. The
original Site and GitHub Pages use independent browser identities.

The source is published to Yiiiiming/xxx, under everything-100/, on main.
All asset paths are relative so the site works in this subdirectory.
